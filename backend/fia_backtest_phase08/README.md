# Phase 08 — Signal Attribution

Phase 8 measures how individual FIA signals performed historically.

It supports:
- signal-level grouping;
- separate 4H and 8H analysis;
- observation counts;
- accuracy;
- average realized return;
- average signal score;
- optional directional alignment.

This is descriptive attribution, not proof of causality.

The phase does not modify live FIA weights or forecast logic.

Actual historical results require historical prediction/outcome records.

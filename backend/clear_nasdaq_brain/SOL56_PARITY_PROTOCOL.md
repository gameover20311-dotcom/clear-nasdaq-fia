# V5 Sol Parity Protocol

The challenge is domain-specific: push local `gpt-oss:20b` toward GPT-5.6 Sol behavior on CLEAR NASDAQ FIA work through specialization, atomic evidence, causal reasoning, adversarial verification and calibration. It is not model cloning.

A behavioral-parity claim is forbidden unless a sealed, complete HOLDOUT of >=100 valid paired cases passes the documented similarity, direction-agreement and probability-gap gates. Market edge is scored separately only after genuine future resolution.

## Blind benchmark ceremony
1. Finish TRAIN/DEV iteration.
2. Capture the final HOLDOUT cohort.
3. Run `freeze_benchmark.py` to seal the FULL reasoning code, config, calibration and cases.
4. Record the printed `seal_sha256` OUTSIDE the project directory (for example in an immutable chat/audit record or a separate signed commit record).
5. Produce first-write local and GPT-5.6 Sol outputs; HOLDOUT replacement is forbidden by code.
6. Score only with a valid seal and complete cohort.
7. Record the final result/output hashes outside the project too.

Local files alone cannot prevent a malicious operator from deleting the entire history; external recording of seal hashes is therefore required for serious public claims.

# Phase 12 — Final Dashboard

The Final Dashboard consolidates the FIA Backtest Lab phases.

It reports:
- phase completion/status;
- historical data availability;
- real performance availability;
- a warning when real historical prediction/outcome data is absent.

It exports:
- `output/final_dashboard.json`
- `output/final_dashboard.txt`

Important:
No performance numbers are fabricated.

The dashboard does not modify live FIA weights or forecast logic.
